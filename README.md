# 🤖 Управление роботами-доставщиками (Autonomous Delivery Robots Fleet Routing & ETA Prediction)

Автоматическая система расчета времени прибытия (ETA), планирования маршрутов и управления парком роботов-доставщиков с учетом погоды и пробок.

> 💡 **Специфика данных:** Логи движения автономных роботов являются строгой коммерческой тайной крупных компаний. Чтобы решить проблему нехватки открытых данных, в рамках проекта была создана **математическая модель симуляции данных на 1 000 рейсов**. Модель воссоздает физику движения роверов и учитывает реальные городские факторы: пешеходные заторы, часы пик и плохую погоду (снегопад, гололед), которая ухудшает сцепление колес и создает шумы для датчиков (лидаров).

Система объединяет в себе генерацию реалистичных логов движения, хранение информации в базе данных SQL, поиск кратчайших путей на картах и точное прогнозирование времени прибытия с помощью машинного обучения.

---

## 📈 Бизнес-метрики и эффективность модели
* **Оптимизация логистики:** Анализ собранных данных через SQL помог найти самые загруженные перекрестки города с максимальным количеством заказов. Это позволяет компании заранее расставить там резервные зарядные станции для роботов.
* **Главные факторы задержек:** Математический анализ показал, что сильнее всего на время в пути влияет длина маршрута, а сразу за ней идут плотность пешеходов на тротуарах и погодные условия.
* **Высокая точность прогноза:** Модель машинного обучения на базе градиентного бустинга (Gradient Boosting) показала отличные результаты:
  * **Точность модели:** `91.20%`
  * **Средняя ошибка:** всего `1.15 мин` — алгоритм ошибается в расчете времени прибытия робота в среднем всего на **69 секунд**.

## 🛠️ Стек технологий и архитектура
* **Данные и SQL:** СУБД SQLite (проектирование таблиц, сбор сырых логов с бортовых компьютеров роботов, написание аналитических запросов).
* **Поиск маршрутов (Графы):** Библиотека `NetworkX` (создание цифровой модели микрорайона с дорогами и перекрестками, автоматический поиск самых коротких и безопасных путей для роверов).
* **Машинное обучение:** Python 3.11, алгоритм Градиентного бустинга (`GradientBoostingRegressor`), библиотека Scikit-Learn для обучения модели и проверки её точности.
* **Анализ данных и графики:** Библиотеки Pandas, NumPy, Seaborn, Matplotlib.
* **Понятные отчеты:** Автоматическое программное создание строгого 6-страничного отчета в формате PDF с графиками для технического директора логистической компании.
