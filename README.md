# 🤖 Управление роботами-доставщиками (Autonomous Delivery Robots Fleet Routing & ETA Prediction)

Автоматическая система расчета времени прибытия (ETA), планирования маршрутов и управления парком роботов-доставщиков с учетом погоды и пробок.

> 💡 **Специфика данных:** Логи телеметрии автономных логистических систем являются строгой коммерческой тайной LogTech-операторов. Для преодоления дефицита открытых данных в рамках проекта была спроектирована и программно реализована **математическая модель симуляции IoT-данных на 1 000 рейсов**. Модель воспроизводит физику движения роверов и генерирует нелинейные задержки на основе реальных городских факторов: пешеходных заторов, часов пик и метеорологических аномалий (снегопад, гололед), ухудшающих сцепление колес и зашумляющих показания лидаров.

Архитектура системы объединяет генерацию симуляционных логов, реляционное моделирование в СУБД SQLite, граф-анализ топологии сети и автоматическое управление движением на базе алгоритмов машинного обучения.

---

## 📈 Бизнес-метрики и эффективность модели
* **Оптимизация логистических процессов:** Анализ агрегированной SQL-витрины логов позволил локализовать ключевые перекрестки-хабы мегаполиса с максимальной плотностью заказов для проактивного размещения резервных зарядных станций.
* **Факторный анализ (Feature Importance):** Математический весовой анализ доказал, что ключевым драйвером времени хода ровера является расстояние маршрута, за ним следуют плотность пешеходных заторов на тротуарах и погодные условия.
* **Качество работы алгоритма и прогноза:** Модель машинного обучения на базе градиентного бустинга (Gradient Boosting) продемонстрировала следующие показатели на тестовой выборке:
  * **Точность модели (R²):** `91.20%`
  * **Средняя абсолютная ошибка (MAE):** `1.15 мин` — алгоритм ошибается в расчете времени прибытия ровера в среднем всего на **69 секунд**.

## 🛠️ Стек технологий и архитектура
* **Данные и SQL:** СУБД SQLite (проектирование реляционных схем, консолидация сырых логов телеметрии бортовых компьютеров, аналитические агрегированные запросы).
* **Граф-анализ:** Библиотека `NetworkX` (построение топологической модели микрорайона, абстракция перекрестков и ребер дорог, реализация алгоритма Дейкстры для автоматического поиска кратчайших безопасных траекторий).
* **Машинное обучение:** Python 3.11, ансамблевое обучение (`GradientBoostingRegressor`), библиотека Scikit-Learn (метрики качества, разделение выборок).
* **Анализ данных и графики:** Библиотеки Pandas, NumPy, Seaborn, Matplotlib.
* **BI-отчетность для бизнеса:** Автоматическое программное формирование строгого 6-страничного альбомного PDF-отчета корпоративного формата для технического директора логистической компании с помощью модуля `matplotlib.backends.backend_pdf.PdfPages`.
