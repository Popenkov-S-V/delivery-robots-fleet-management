# 🤖 Управление роботами-доставщиками (Autonomous Delivery Robots Fleet Routing & ETA Prediction)

Интеллектуальная система предиктивного анализа, пространственного планирования маршрутов и диспетчеризации флота автономных роботов-доставщиков (роверов) в условиях плотной городской застройки мегаполиса. Пайплайн проекта охватывает сбор телеметрии, реляционное моделирование в СУБД SQLite, граф-анализ топологии сети и предиктивное управление движением на базе алгоритмов машинного обучения.

---

## 📈 Бизнес-метрики и эффективность ИИ
* **Оптимизация логистических процессов:** Анализ агрегированной SQL-витрины логов позволил локализовать ключевые перекрестки-хабы мегаполиса с максимальной плотностью заказов для проактивного размещения резервных зарядных станций.
* **Факторный анализ (Feature Importance):** Математический весовой анализ доказал, что ключевым драйвером времени хода ровера является расстояние маршрута, за ним следуют плотность пешеходных заторов на тротуарах и погодный код.
* **Качество ИИ-классификации и прогноза:** Предиктивная модель ансамблевого градиентного бустинга (Gradient Boosting) продемонстрировала следующие показатели на скрытой тест-выборке:
  * **Коэффициент детерминации (R²):** `91.20%`
  * **Средняя абсолютная ошибка (MAE):** `1.15 мин` (ИИ ошибается в расчете времени прибытия ровера в среднем всего на **69 секунд**).

---

## 🛠️ Стек технологий и архитектура
* **Данные и SQL:** СУБД SQLite (проектирование реляционных схем, консолидация сырых логов телеметрии бортовых компьютеров, аналитические когортные запросы).
* **Граф-анализ:** Библиотека `NetworkX` (построение топологической модели микрорайона, абстракция перекрестков и ребер дорог, реализация алгоритма Дейкстры для автоматического поиска кратчайших безопасных траекторий).
* **Машинное обучение:** Python 3.11, Ансамблевое обучение (`GradientBoostingRegressor`), Scikit-Learn (метрики качества, разделение выборок).
* **Анализ данных и визуализация:** Pandas, NumPy, Seaborn, Matplotlib.
* **BI-отчетность:** Автоматическое программное формирование строгого 6-страничного альбомного PDF-отчета корпоративного формата для технического директора логистической компании с помощью модуля `matplotlib.backends.backend_pdf.PdfPages`.
